**Feliactyl** is a free, open-source client dashboard for [Pterodactyl](https://pterodactyl.io/). It gives your users a polished interface to create and manage game servers, earn virtual coins, and purchase resources — without ever needing Pterodactyl admin access.

:::tip Quick Install
```bash
bash <(curl -s https://raw.githubusercontent.com/notcaliper/Feliactyl/v2-features/install.sh)
```
Or follow the [full Installation Guide →](./installation)
:::

## Requirements

| Requirement | Details |
|:---|:---|
| **OS** | Ubuntu 20.04+ / Debian 11+ |
| **Node.js** | 20.x LTS |
| **Panel** | Pterodactyl v1.x |
| **Domain** | Pointed at your VPS |
| **Discord App** | OAuth2 enabled |

---

## Tech Stack

Built on proven, production-ready open-source software:

- **[Express.js](https://expressjs.com/)** — web framework
- **[EJS](https://ejs.co/)** — templating engine
- **[Keyv](https://keyv.org/) + SQLite** — database (PostgreSQL & MySQL supported)
- **[PM2](https://pm2.keymetrics.io/)** — process manager & clustering
- **[Helmet.js](https://helmetjs.github.io/)** — security headers
- **[Stripe](https://stripe.com/)** — optional real-money payments

---

## Origin

Feliactyl is a fork of [Heliactyl](https://github.com/Heliactyl/Heliactyl), completely rewritten from **v2.0** onwards with:
- New microservices architecture
- Atomic economy transactions
- Comprehensive firewall system
- Full settings editor UI
- Referral system & 2FA
